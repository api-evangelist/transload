# Transload

> Transload (YC Spring 2026) measures freight with security cameras. It turns the CCTV cameras already installed in logistics warehouses into a 3D dimensioner for the loading dock, using computer vision to capture the true size of every pallet and parcel as it moves through the warehouse — no new hardware or process changes. Founded 2026 in San Francisco by Nils Börner, Julius Scheel, and Jago Wahl-Schwentker.

## API

- [API reference (Swagger UI)](https://api.transload.io/docs): Pipeline Backend API, OpenAPI 3.0.3, 125 paths / 145 operations
- [OpenAPI JSON](https://api.transload.io/docs/json): served publicly by the production host
- Base URL: https://api.transload.io (all operations require bearer authentication; unauthenticated requests return a JSON error envelope {code, message, details, requestId})
- Resources: customers, sites, cameras, media assets, ingestor captures, scans (ingestion → dewarping → classification → measurement → QA stages), processing jobs, AI results, reference measurements, handling units, customer data (handling units, shipments), QA review surfaces
- Auth flows in spec: customer magic-link auth (/v1/customer/auth/request-link, /verify, /session, /select-customer, /logout), /refresh-token, /admin/login
- Pagination: limit/offset (default limit 50); cursor on some endpoints
